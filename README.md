# InsightRadar-AI-News-Trend-Insight-Engine
InsightRadar（智能洞察雷达）是一个面向研究者、产品、投资与创作者的 AI 趋势洞察系统。它不回答「发生了什么」，而是回答：「什么正在形成共识、什么正在失控、什么值得提前注意」。 系统从多源信息（RSS、网页、本地文档等）统一摄取并做语义主题聚合，为每个主题计算趋势强度（0–100）、多维度情绪与立场分析，并生成一句洞察标题、强度解释、风险/机会提示和可回溯引用。输出支持 JSON、Markdown 与 API，可每日定时抓取与更新，仅在趋势显著变化时生成新洞察，不预测价格、不提供投资建议，适合用作研究、产品与创作的趋势雷达。
